# Mini E-Commerce Mobile App

A small React Native e-commerce app built with Expo and JavaScript for the React Native Developer Intern assignment.

## Features

* Mock login with validation
* Product listing using DummyJSON API
* Search and category filtering
* Product details
* Add, update, and remove cart items
* Cart subtotal and item count
* User profile and logout
* Bottom-tab and stack navigation
* Loading, error, and empty states

## Tech Stack

* React Native
* Expo
* JavaScript
* React Navigation
* Context API
* DummyJSON

## Run Locally

```bash
npm install
npx expo start
```

Then scan the QR code with **Expo Go**, or press `a` / `i` to run on an Android/iOS emulator.

## API

`https://dummyjson.com/products`

## Note

Authentication and checkout are mock implementations. Login and cart data are not persisted after closing the app.
